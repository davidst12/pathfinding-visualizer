# Pathfinding Visualizer

Proyecto en C++ para visualizar algoritmos de búsqueda en un mapa interactivo.

## Características
- Visualización paso a paso de BFS, DFS, A*, Dijkstra
- Interfaz gráfica con SFML
- Tests unitarios con Catch2

## Compilación
```bash
cd build
cmake ..
make
```

## Run
```bash
cd build && make
./pathfinding_visualizer
```

## Tests
```bash
cd build && make
./unit_tests
````
